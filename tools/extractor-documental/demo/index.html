1 · Capa 0 — ¿hace falta el motor?

Suelta aquí un PDF (o pulsa para elegirlo)
Quita el texto de la pantalla. El archivo nunca salió de tu equipo: la capa 0 corre aquí.

Un PDF generado por software trae su texto dentro y se resuelve sin llamar al motor. Ante cualquier duda —cifrado, escaneo, texto ilegible— llama: un falso negativo cuesta una llamada, un falso positivo mete datos corruptos con apariencia de exactos y sin pasar por la cola.

2 · Ingesta — arrastra una carpeta entera

Suelta archivos o una carpeta

Soltar una carpeta y elegirla son dos mecanismos distintos del navegador. Lo que se rechaza se nombra con su archivo y su motivo: el rechazo silencioso es como se pierden documentos.
