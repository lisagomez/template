1 · Capa 0 — ¿hace falta el motor?

Suelta aquí un PDF (o pulsa para elegirlo)
Quita el texto de la pantalla. El archivo nunca salió de tu equipo: la capa 0 corre aquí.

Un PDF generado por software trae su texto dentro y se resuelve sin llamar al motor. Ante cualquier duda —cifrado, escaneo, texto ilegible— llama: un falso negativo cuesta una llamada, un falso positivo mete datos corruptos con apariencia de exactos y sin pasar por la cola.

8 · Motor de OCR — para lo que la capa 0 no puede leer

Esto manda tu documento al servidor que pongas abajo. Pon uno tuyo. «Autohospedado» describe quién corre el modelo, no por dónde viaja el byte: apuntar aquí a un servidor ajeno saca el documento de tu perímetro igual que una API comercial.

Por eso no hay aquí un campo para una clave de API comercial. Si el documento lleva datos de personas que no decidieron nada —clientes, empleados, menores— esa vía no se ofrece.
Suelta aquí el documento escaneado (PDF o imagen)

De un PDF escaneado se saca el JPEG que ya lleva dentro y se manda ese. No se rasteriza: eso pediría una dependencia de render que el núcleo no tiene. Si el PDF trae capa de texto, la capa 0 lo resuelve sin motor y sin coste — pruébalo arriba antes de gastar aquí.
